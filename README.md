# 开心消消乐 v1.2 · 森林大冒险

用 Three.js 实现的 3D 三消游戏：六只程序化精细建模的小动物（狐狸 / 小鸡 / 青蛙 / 企鹅 / 小猪 / 熊猫），特效动物与组合技，冰层、木箱、藤蔓、橡果等关卡机制，15 个手工设计的异形关卡，以及用 Web Audio API 实时合成的音乐与音效。所有模型、贴图和声音都由代码生成，没有外部素材。

在线试玩：https://liyucheng1997.github.io/305_game-happy-match/

版本更新见 [CHANGELOG.md](CHANGELOG.md)。

## 玩法

- **交换**：拖动一只动物到相邻格子，或先后点击两只相邻动物。横竖连成 3 个即可消除；无效交换不扣步数。
- **特效动物**
  - 连成 4 个 → 疾风动物（金色光圈 + 箭头），引爆时清除整行或整列
  - L / T 形 → 炸弹动物（橙色尖刺光环），炸开周围区域
  - 连成 5 个 → 彩虹球，与任意动物交换即可消除全盘同类
- **组合技**：交换两个特效直接触发，不需要三连
  - 疾风 + 疾风 = 十字清除；疾风 + 炸弹 = 三行三列；炸弹 + 炸弹 = 超大爆炸
  - 彩虹 + 特效动物 = 同类全部变成该特效并引爆；彩虹 + 彩虹 = 清空全盘
- **关卡机制**
  - 冰层：在冰上消除动物即可破冰，深蓝厚冰需要两次
  - 木箱：在旁边消除或用特效打碎，带铁箍的要敲两次；木箱会挡住下落，动物会从斜上方滑入
  - 藤蔓：被缠住的动物不能移动，参与一次消除即可解开
  - 橡果：把它送到棋盘最底部（绿色箭头处）就会被收集
  - 异形棋盘：空缺处动物会直接穿过落下
- **魔法道具**：消除动物积攒能量（上限 60），道具不消耗步数
  - 小木槌（12）：一次敲碎一格的全部木箱 / 冰层 / 藤蔓
  - 蒲公英炸弹（28）：炸开 3×3
  - 彩虹魔法（45）：消除全盘同类
  - 洗牌（20）：重新排列动物，障碍不动
- **结算**：完成全部目标即过关，剩余步数会在「森林狂欢」中变成疾风动物并全部引爆。通关得一星，分数达到二星 / 三星线再加星。
- 闲置 6 秒会提示一步可走的交换；无路可走时自动免费洗牌；进度与最高分保存在浏览器里。

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173 。构建生产版本：`npm run build`。

## 结构

```
index.html          页面与 HUD
src/levels.js       动物、关卡、道具与存档（纯数据）
src/engine.js       三消引擎：匹配、特效、组合技、障碍、重力、橡果，输出动画步骤（不依赖 Three.js）
src/models.js       程序化建模：动物、橡果、彩虹球、特效装饰、冰层、木箱、藤蔓、木槌
src/world.js        森林场景与随关卡形状生成的木质棋盘
src/fx.js           粒子、光束、冲击波、彩虹闪电
src/ui.js           顶栏、道具栏、关卡地图、开场横幅、结算
src/main.js         渲染循环、输入、步骤动画播放、关卡流程
src/audio.js        音乐与音效合成
scripts/simulate.mjs 关卡平衡模拟（贪心机器人）
```

## 验证

- `npm test`：14 项引擎与关卡规则测试（特效生成、组合技、障碍、重力、橡果、洗牌、结算，以及 15 关的长时间随机对局）。
- `npm run simulate`：贪心机器人反复游玩每一关，输出胜率与得分分布，用来校准步数和星级分数线。
- `npm run test:e2e`：浏览器测试（地图开局、拖动交换、特效组合与道具、过关保存与手机布局）。首次运行前执行 `npx playwright install chromium`，或设置 `PLAYWRIGHT_CHANNEL=chrome` 使用已安装的 Chrome。
