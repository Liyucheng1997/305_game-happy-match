# 开心消消乐 v1.1 · 森林冒险

用 Three.js 实现的 3D 三消游戏：8×8 棋盘、6 种手工建模的动物头（猫 / 狗 / 猪 / 熊 / 青蛙 / 兔子）、连锁消除、粒子特效，以及用 Web Audio API 实时合成的背景音乐与音效。

在线试玩：https://liyucheng1997.github.io/305_game-happy-match/

版本更新见 [CHANGELOG.md](CHANGELOG.md)。

## 玩法

- 点击一个动物，再点击相邻动物进行交换
- 横 / 竖 3 个及以上相同动物连成一线即可消除
- 消除后上方动物下落并补充新动物，自动连锁，连击有分数加成
- 12 个递进关卡：同时达成分数、指定动物收集和破冰目标即可过关；步数用完则失败
- 前 4 关使用 5 种动物，之后增加至 6 种；步数从 26 逐步降至 21，第三关出现冰层，第七关出现双层冰
- 普通消除每只动物获得 1 能量（上限 60），每关初始 12 能量
- 破冰锤（12）：消除一格并击碎该格全部冰层；范围炸弹（28）：消除 3×3 区域；彩虹魔法（45）：消除全盘同类动物；洗牌（20）：重置动物布局并保留冰层
- 技能不扣步数，技能及其连锁不返还能量；再次点击技能或按 Esc 取消选中
- 冰层固定在棋盘格上，每次消除该格的动物削掉一层；无解时自动免费洗牌
- 结算会等待全部连锁结束，最后一步达成目标仍可通关；零步时不能再使用技能
- 剩余步数达到初始步数的 35% / 15% 分别获得三星 / 二星，其他通关为一星
- 自动保存最高星级和解锁关卡到当前浏览器；可以在关卡菜单重玩已解锁关卡

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173 。

构建生产版本：

```bash
npm run build
```

## 技术

- [Three.js](https://threejs.org/) — 场景、灯光、阴影、射线拾取
- [Vite](https://vitejs.dev/) — 开发与构建
- Web Audio API — 无外部素材的音乐与音效合成（`src/audio.js`）

## 结构

```
index.html        页面与 HUD
src/main.js       游戏逻辑、动物建模、动画、渲染
src/audio.js      音乐与音效
src/style.css     样式
```

## 验证

`npm test` 运行规则测试。`npx playwright install chromium` 安装测试浏览器后，运行 `npm run test:e2e` 检查技能、冰层、过关保存与移动端布局。也可以设置环境变量 `PLAYWRIGHT_CHANNEL=chrome` 使用已安装的 Chrome。
